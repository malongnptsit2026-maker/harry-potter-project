# Harry Potter Character Explorer ⚡

## About the Project

Harry Potter Character Explorer is a website that displays characters
from the Harry Potter universe.

It uses a public API to retrieve character information and displays
the information in a user-friendly website.

## Technologies Used

- Node.js
- Express.js
- Axios
- EJS
- HTML
- CSS
- Harry Potter API

## Features

- Display Harry Potter characters
- Search characters by name
- Display character images
- Display character houses
- Display actor names
- Display species information
- Responsive design for mobile and desktop
- API error handling

## API

Harry Potter API:

https://hp-api.onrender.com/api/characters

## Installation

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Install the required packages:

   npm install

5. Start the server:

   npm start

6. Open your browser and visit:

   http://localhost:3000

## Development Mode

You can also use Nodemon to restart the server automatically
when you make changes.

Run:

npm run dev
